📋 One-time Google Apps Script setup (5 minutes)
  1. Go to script.google.com → click New Project
  2. Delete all code in the editor, paste in the GoogleAppsScript_Code.js file provided
  3. Click Run → setupManually (first time only — authorizes Drive + Sheets access)
  4. Click Deploy → New Deployment
  5. Type: Web App · Execute as: Me · Who has access: Anyone
  6. Click Deploy → copy the Web App URL
  7. Paste that URL into the field above and click Save
